# Security policy

This policy covers every repository of Argon Labs that does not have its own. Argon itself has a more detailed policy in [argon-lab/argon](https://github.com/argon-lab/argon/blob/master/SECURITY.md).

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Email **security@argonlabs.tech**, or
- use GitHub's "Report a vulnerability" button on the repository's Security tab.

Say which repository and version are affected, what you observed, and how to reproduce it if you can. You will get an acknowledgement, and we will tell you what we find and when a fix is released.

## Supported versions

Fixes go into the latest release of each project: Argon (`argonctl`) 2.x, the `argon-agents` Python package, and the Homebrew formula in `argon-lab/homebrew-tap`. `argon-lab/benchmarks` is a measurement suite and is not shipped; report problems in its scripts the same way.
