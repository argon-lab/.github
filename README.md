# argon-lab/.github

Organization-wide files for [Argon Labs](https://github.com/argon-lab).

- `profile/README.md` is the text shown on the organization's GitHub page.
- `profile/assets/` holds the Argon Labs mark: a purple disc with argon's outer shell of eight electrons around the element tile, `#5140D8` and `#DCD8F7`, Archivo type converted to paths.

| File | Use |
| --- | --- |
| `icon.svg`, `icon.png` | the mark, transparent background |
| `avatar.svg`, `avatar.png` (512 px, opaque) | the organization avatar; safe for GitHub's circle crop |
| `lockup-light.svg`, `lockup-dark.svg` | mark plus "Argon Labs" for light and dark backgrounds |
| `social-preview.svg`, `social-preview.png` (1280×640) | link previews |

The product marks live with their repositories: Argon in [argon-lab/argon](https://github.com/argon-lab/argon), Argon Cloud in its own repository.
